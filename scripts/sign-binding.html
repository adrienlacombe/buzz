NIP-SW binding signer

Signs a SNIP-12 typed-data document with an injected Starknet wallet (Xverse, Ready/Argent, Braavos). Typed data cannot be pasted into a wallet's "sign message" box — that box signs a plain shortstring, which is why a 645-byte JSON document is rejected as "too long". It has to go through the wallet's programmatic signing API, which is what this page does.

Everything runs locally in this page. No network calls, no key material leaves the wallet.
